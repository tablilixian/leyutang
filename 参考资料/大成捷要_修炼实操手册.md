# 《大成捷要》修炼实操手册

> 本文档基于清代丹经要语汇编《大成捷要》原文整理，是**丹道天元大丹清净丹法**的实修参照。原文以"二十四节口诀"组织全篇，对应**炼精化气、炼气化神、炼神还虚、炼虚合道**四个阶段，依次贯通"百日筑基→采大药→七日混沌→十月养胎→调神出壳→三年乳哺→九年面壁"之完整次第。
>
> 原文云："此册二十四节真诀，三十六层危险口口叮传，心心相印，句句可考。"本文档逐节梳理功法定位、操作要领、时机判断与危险防备，以备实修者参照。

## 二、百日筑基（炼精化气）

**阶段定位：** 初成小成筑基功夫。返还到本体未破、乾坤交泰之地，名曰**人仙**。
**总纲：** 调药补精，炼精化气。收心还虚，固精养气。三百周天数足，阳光三现，转入采大药。

### 第1节 还虚蛰藏气穴

| 项目 | 内容 |
|------|------|
| 功法定位 | 下手第一着，百日筑基起手 |
| 操作要领 | 静室端坐，返观内照，凝神入命门气穴。**知而不守，先存后亡**，虚心凝神，不着色相，不落空亡。以三炷香为度。心止脐下曰凝神，气蛰脐下曰胎息。守其清静自然曰**勿忘**，顺清静自然曰**勿助**。 |
| 时机判断 | 行不过七七日，水火交而真阳产。凝照三月方结丹，凝照百日透关过窍。 |
| 危险防备 | 须先绝食腥荤香辣；过饱伤神，过饥伤气；动静失宜则阴阳偏盛。 |

### 第2节 调药风火妙用

| 项目 | 内容 |
|------|------|
| 功法定位 | 百日筑基调外药 |
| 操作要领 | 半夜子时后，一阳来复、外肾兴起时行功。**风=呼吸，火=虚灵之神。文=无为之风火，武=有为之风火**。文火用于调药前后两头，武火用于元精正旺之时。真意眸光凝入命宫，鼓动巽风，扇开炉焰，一意不散。 |
| 时机判断 | 外肾消缩净尽，元气皈宿坤炉，即止武火。 |
| 危险防备 | 武火太轻则阴精累积走失；武火太重则肚腹疼痛、大便溏泻。不可着意口鼻，猛烈短促。 |

### 第3节 产药玄窍真种

| 项目 | 内容 |
|------|------|
| 功法定位 | 真种产出之候 |
| 操作要领 | 收心炼己，回光返照，精气于下田。**知而不守，神潜太虚**，一念不起，万缘皆空。 |
| 时机判断 | 丹田融融洽洽，周身稣快乐，痒生毫窍；阳物勃然兴起，顶门冷气吹入；气穴中忽然一吼，呼吸顿断倒回元海；冬冬有声，一连三五次或六七次。**不老不嫩**为真时：玉洞双吹已过、阳物已衰为老；一吼气住、呼吸倒回元海为嫩。 |
| 危险防备 | 太早则药嫩气微不灵；太迟则药老气散不聚。 |

### 第4节 炼药周天火符

| 项目 | 内容 |
|------|------|
| 功法定位 | 小周天火候，炼精化气正功 |
| 操作要领 | 用**吸舐撮闭**四字真诀采药皈炉。**吸**：鼻中吸气接先天；**舐**：舌舐上腭迎甘露；**撮**：紧撮谷道内中上提；**闭**：塞兑垂帘回光返照紧闭六门。封固后行周天：子进阳火（后升，乾用九，二百一十六吸），午退阴符（前降，坤用六，一百四十四呼），卯酉沐浴（神住夹脊/黄庭，默记36吸/24呼）。 |
| 时机判断 | 三百六十息合度周天数足；久行至**马阴藏相**、龟头缩回；**阳光一现**（眉间掣电）。 |
| 危险防备 | 念起则火炎；意散则火冷；外视伤魂，外听伤魄；呼吸骤则散漫，呼吸停则断续。气荡则流窜经络，气滞则拥塞濡滞。吕祖三败、邱祖四败，火候细微不可不慎。 |

| 操作要领 | 龟缩不举、阳光二现时止火。常温养，刻刻凝照。**二现止火，三现采药**。 |
| 时机判断 | **阳光二现**：静定中坤田丹光上涌达目，明如金钱、赤如火珠，从大眼角流下成珠。此为大药将产之时。 |
| 危险防备 | 火未足而止火，大药不生；火已过而止火，真气不聚，必倾危。**阳光四现则大药走失**，前功尽废。须于二现止火、三现速采，不速不迟。 |

## 三、采大药·七日混沌（炼精化气→炼气化神之过渡）

## 四、十月养胎（炼气化神）

**阶段定位：** 中成养胎功夫，名曰**地仙**。
**总纲：** 安元神于祖窍（黄庭），文火温养，守中抱一，七返九还，金液玉液还丹，五气朝元，神俱六通。

### 第9节 结胎大蛰七日

| 项目 | 内容 |
|------|------|
| 功法定位 | 大药服食后，结胎之始 |
| 操作要领 | 先行卯酉周天一遍团聚大药。主静立极，行**七日大蛰之功**。深入寂灭，大休歇一回。混沌七日，轻轻寂照，绵绵若存，不即不离，文火沐浴，忘形无我。外不知有身，内不知有心。 |
| 时机判断 | 七日之外有来复之机，玉液复生。如气绝身死一般，七日后方苏。 |
| 危险防备 | 七日外若不唏醒，恐元神静中出舍坠入轮回。须以钟盘耳边击鸣、缓缓揉拍其背、呼其名字，或从阴跷穴点之，自然还阳。**接命之时，便是伤命之处**。 |

### 第10节 七返玉液还丹

| 项目 | 内容 |
|------|------|
| 功法定位 | 小坎离交媾 |
| 操作要领 | 静定日久，坎中热气冲心，真意引过尾闾由夹脊透玉枕入泥丸。自上腭颗颗下降口中，状如雀卵，味似阳酥，化为金液沥沥如淋水。以意迎之徐徐咽下重楼，以目送入炉鼎。一连九日咽纳不绝。每回运卯酉周天以收之。 |
| 时机判断 | 静极无心中而动，金液降完即凝神入定守中抱一。 |

### 第11节 九还金液还丹

| 时机判断 | 每回皆运卯酉周天收之，待玉液降完即凝神入定。 |

| 操作要领 | 皈入中宫温养圣胎。静定之极不醒人事、气息全无、六脉皆住。凝神入定，金木交合。真铅化为明月、真汞化为红日。静定中见明月缭绕，真意留而待之；三五息间日光出现与月光相合，**日月交光合发金花二朵，状如仙丹，金红赤色五瓣分明**，名曰"玉蕊金花"。念头牢把，伴归一处悬于印堂。运动真意凝聚收敛蛰藏，鼻吸入丹田虚危穴，后升前降皈入中宫与仙胎混而为一。 |

## 五、调神出壳（炼神还虚之始）

## 九、炼己与火候通则

### 炼己通则

> "未炼还丹先炼己，炼己纯熟而后还丹，则心死神活也。"

- 专看念头起时坚持正觉，杂念扫除皈于一念
- 主静立极，还虚入定，扫除三心，灭尽四相
- 真意往来无间断，知而不守是功夫
- 着意头头错，无为又落空
- **收回来须放下**，从有心化为无心

- 巽风太过、离火不足：肚腹疼痛大便溏泻
- 意住口鼻：外吸冷气入内

## 十二、实修总则

1. **财侣法地**："只用有财有侣，真心修炼，即能超凡而入圣。"——须择人迹罕到、鸡犬不闻之所，外有知音道友护持。
2. **三事并至**：火候无差恰恰运满三百周天之数；马阴藏相龟身缩入腹里；阳光二现掣电两眉之间。三者参明透彻方止火。
3. **死心为主**：任千变万化，总以死心入定为主，喜惧哀乐不动为宗。"**你会六神通，才能脱生死**"。
4. **末后一着**："阅尽丹经万万篇，末后一句无人说。"——炼虚合道最难，千万人中难得一二人。
5. **慎之又慎**："天机口诀，句句明言，勿轻视天宝，慎哉慎哉，免遭天谴，妄传非人，雷诛火焚，可不慎欤。"
